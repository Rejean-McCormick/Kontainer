# English documentation translation

This distribution is based on the supplied snapshot. README files and French-language Markdown documentation have been translated into English. Executable code, data, schema definitions and CLI identifiers have not been translated or otherwise intentionally changed. Source filenames have been preserved so internal links and code references continue to work.

The `vendor/Kristal-Authoring-Kit/` directory (when present) is an upstream bundled dependency and was deliberately left unchanged, including any French-language documents within it.

Some GUI labels, commands, data filenames and quoted test strings remain in French because those are the exact labels or identifiers implemented in the unchanged application.

Historical snapshot or consolidation records refer to earlier source bytes and do not constitute a fresh software qualification. The `TRANSLATION_MANIFEST_EN.json` file compares original and translated document fingerprints.

No source repository, GitHub branch or remote release was modified.
